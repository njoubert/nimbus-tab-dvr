# Research

What was established from primary sources, before a plan rested on it.

## What a research note is

**A research note answers one question against live primary sources**, official specifications, vendor documentation, source code, and dated forum threads, and it names the date it was written at the top.
A conclusion drawn from a source is only as fresh as the source, and a reader has to be able to tell.

**Every note ends with a "Verified vs. unverified" section**, plus a sources list with the fetch status of each one.
Anything marked unverified is a hypothesis, not a fact, and a plan that rests on one says so.

**A note is maintained, unlike a report.**
When a source changes, the note is rewritten in place and its date is updated.

## Naming

```text
short-slug.md
```

**A research note is named for its question**, because it is consulted by subject rather than by date.
The date lives inside it.
